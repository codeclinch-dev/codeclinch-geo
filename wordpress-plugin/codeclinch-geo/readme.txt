SEO metadata, structured data, crawler policy, and opt-in discovery exports for WordPress.

== Description ==

Interdeft provides SEO settings, schema, redirect and crawl diagnostics, discovery exports, and admin reports. It extends the WordPress sitemap when WordPress owns SEO output and yields overlapping output to recognized SEO plugins. WooCommerce remains the source for current Product structured data.

Discovery exports and footer attribution are opt-in for fresh installations. Discovery publishes metadata from selected public canonical pages. The optional OpenAI and OpenRouter tools send site information to the selected provider when an administrator enables the integration, consents, and requests a draft.

== Installation ==

1. Upload the Interdeft ZIP through Plugins > Add Plugin > Upload Plugin.
2. Activate Interdeft SEO & AI Search.
3. Open the Interdeft menu to configure metadata, crawler policy, and discovery exports.

The plugin folder retains its previous name for upgrades. Existing per-page metadata, options, old sitemap URLs, and shortcodes remain available.
